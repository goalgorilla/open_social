# Open-source modules

The entirety of the distribution is open source. However, modules in this
folder are intended to be moved outside the distribution as standalone modules.
Open Social's internal monorepo versioning currently conflicts with the
distribution requiring those same modules.

Modules in this folder may not depend on anything else in the distribution and
should work standalone.

If you rely on modules in this folder, be prepared that you may need to
depend on a different project at some point.
