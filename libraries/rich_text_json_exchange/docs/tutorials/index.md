# Tutorials

Step-by-step guides that teach you how to use the Rich Text JSON Exchange library through hands-on practice.

## Prerequisites

- PHP 8.3 or higher
- Composer
- Basic familiarity with the [OpenSocial Rich Text JSON Exchange specification](../../Open-Social-Rich-Text-JSON-exchange-format.pdf)

## Available Tutorials

Work through these tutorials in order:

### 1. [Getting Started](getting-started.md)

Parse a JSON document, access the node tree, and serialize back to JSON. This tutorial introduces the basic workflow of the library.

### 2. [Editing Documents](editing-documents.md)

Learn the immutable editing pattern. Create nodes, modify text and formatting, and build documents from scratch using `with*` methods.

### 3. [Validating Documents](validating-documents.md)

Validate documents against structural rules. Understand validation errors and JSON pointer paths.

### 4. [HTML Conversion](html-conversion.md)

Render documents to safe HTML and import HTML back into documents. Understand the round-trip behavior and limitations.

## What You'll Learn

After completing these tutorials, you will be able to:

- Parse and serialize Rich Text JSON documents
- Navigate the document tree structure
- Create and modify documents using immutable APIs
- Validate documents and interpret errors
- Convert between documents and HTML
